360° Rotating Triangular Mop Landing Page

Project Description

A responsive e-commerce landing page built for showcasing and selling a single product — the **360° Rotating Triangular Mop**.

The main goal of the project was to create a functional product page with:

* Structured product presentation
* Interactive media galleries
* Promotional timers
* User order form
* Customer review sections
* Mobile responsiveness

---

What Was Implemented

Layout & Structure

* Built the full page structure from scratch using semantic HTML5
* Organized the page into reusable sections:

  * Header / Hero
  * Product information
  * Media gallery
  * Product advantages
  * Specifications
  * Reviews
  * Order form
  * Footer
* Used BEM naming methodology for scalable CSS structure

---

Styling

* Created custom responsive styling with CSS3
* Used:

  * Flexbox
  * CSS Grid
  * Media-friendly fixed-width mobile layout
  * Keyframe animations
  * Hover states
  * Reusable utility classes
* Implemented:

  * Countdown visual emphasis
  * CTA animations
  * Product urgency indicators
  * Custom rating bars
  * Responsive sliders

---

JavaScript Functionality

Implemented several interactive systems:

Product Gallery

* Integrated Swiper.js for:

  * Main product slider
  * Thumbnail slider
  * Navigation controls
  * Synced image switching

Timers

* Built two independent countdown timers:

  * Promotional offer timer
  * Order urgency timer
* Updated DOM elements dynamically every second

Auto Slider

* Created a custom automatic production-line image slider
* Implemented slide transitions with JavaScript
